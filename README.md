## 퀴즈 주제 선정 이유
## 실행 방법
## 기능 목록
프로그램 실행 시 메뉴에서 번호를 선택하면, 선택 결과에 따라 퀴즈 출제/등록/목록/점수 확인/종료 화면이 출력된다. <br>
퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인 기능이 동작한다. <br>
본인이 선택한 주제의 퀴즈가 5개 이상 포함되어 있다. <br>
프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지된다. (파일 저장) 

프로그램 실행 시 메뉴가 출력되어야 한다.
사용자가 기능을 선택할 수 있어야 한다.
종료 기능이 있어야 한다.
잘못된 입력에 대한 처리가 있어야 한다.
Git: 메뉴 기능 완성 후 커밋한다.
<br>
## 파일 구조
최소 2개 이상의 클래스가 정의되어 있다. (예: Quiz, QuizGame) <br>
기능별로 메서드가 분리되어 있다. (입력 처리/게임 진행/저장 로직 등) <br>
데이터는 프로젝트 루트의 state.json에 UTF-8 인코딩으로 저장하고 불러온다. <br>
